# AI-PROGRAMS 🤖

A collection of Artificial Intelligence algorithms, search techniques, games, and rule-based expert systems implemented in Python.

---

## 📂 Programs Included

### 🧠 Classical Search & Constraint Satisfaction
- **[8-Puzzle Problem](8_puzzle.py)**: Solving the 8-puzzle sliding tile problem using state-space search and heuristics.
- **[N-Queens Problem](n%20queen.py)**: Solving the classic N-Queens puzzle using backtracking search.
- **[Water Jug Problem](waterjug.py)**: State-space search solving the water jug measuring problem.
- **[Travelling Salesperson Problem](Salesman.py)**: Finding optimal tours across multiple destinations.

### 🎮 Games & AI Decision Making
- **[Tic-Tac-Toe](tictactoe.py)**: Interactive Tic-Tac-Toe game featuring intelligent AI moves.
- **[Rock Paper Scissors](rock_paper_scissor.py)**: Classic Rock-Paper-Scissors game against the computer.
- **[Treasure Hunt Game](SinglePlayerGame.py)**: Grid-based single-player navigation game.
- **[AI Treasure Hunt (Heuristic)](Singlepersongame.py)**: Grid navigation game using Manhattan distance as an AI heuristic hint.

### 💡 Expert Systems (Rule-Based Systems)
- **[Agriculture Expert System](Agriculture.py)**: Expert system offering crop advice, fertilizer suggestions, and farming guidance.
- **[Medical Diagnosis Expert System](medical.py)**: Rule-based diagnosis system mapping patient symptoms to potential conditions.
- **[Course Suggestion System](Course_suggestion.py)**: Recommendation system advising academic courses based on student interests.

---

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or later

### Running Any Program
Run any of the Python scripts directly via terminal:
```bash
python 8_puzzle.py
python "n queen.py"
python waterjug.py
python tictactoe.py
```
